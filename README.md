# Makanjuola Benjamin - Portfolio Website

A stunning, modern portfolio website showcasing electrical engineering expertise and professional achievements.

## 🚀 Features

- **Beautiful Design**: Modern glass morphism and gradient effects
- **Interactive Animations**: Particle systems, floating elements, and smooth transitions
- **Responsive Layout**: Optimized for all devices
- **Professional Sections**: Hero, About, Experience, Skills, Achievements, CV, Projects, Contact
- **Performance Optimized**: Built with Next.js 15 and React 19

## 🛠️ Tech Stack

- **Framework**: Next.js 15.1.5
- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS 3.4.1
- **Animations**: Framer Motion 12.0.1
- **Icons**: Heroicons React 2.2.0
- **Utilities**: React Intersection Observer

## 🎨 Design Features

- Custom gradient backgrounds with mesh effects
- Particle animation systems
- Glass morphism UI components
- Interactive hover effects
- Smooth scroll animations
- Professional color scheme

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

1. Clone the repository
\`\`\`bash
git clone https://github.com/yourusername/makben-portfolio.git
cd makben-portfolio
\`\`\`

2. Navigate to frontend directory
\`\`\`bash
cd frontend
\`\`\`

3. Install dependencies
\`\`\`bash
npm install
\`\`\`

4. Run the development server
\`\`\`bash
npm run dev
\`\`\`

5. Open [http://localhost:3000](http://localhost:3000) in your browser

## 📦 Build for Production

\`\`\`bash
cd frontend
npm run build
npm start
\`\`\`
